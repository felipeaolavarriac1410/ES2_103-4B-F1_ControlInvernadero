# Mi Primera Aplicación

Un proyecto inicial de Android creado para aprender los conceptos básicos del desarrollo móvil.

## Lo que hicimos hoy

1. **Exploración del Proyecto**: Analizamos la estructura básica de un proyecto de Android utilizando Kotlin y Gradle, identificando los archivos de configuración, el módulo `app` y el código fuente principal (`MainActivity.kt` y `activity_main.xml`).
2. **Modificación de la Interfaz (UI)**: 
   - Editamos el archivo `activity_main.xml`.
   - Agregamos un componente `ImageView` para mostrar el logo de Inacap (`@drawable/logo_inacap`).
   - Ajustamos los _constraints_ para centrar la imagen horizontalmente, agregar un margen superior de `32dp`, establecer un tamaño de `96x96dp` y acomodar el `TextView` original ("Hola Mundo") para que aparezca justo debajo del logo.
3. **Control de Versiones y GitHub**:
   - Inicializamos el repositorio local con Git.
   - Creamos y publicamos el proyecto de forma pública en GitHub.
